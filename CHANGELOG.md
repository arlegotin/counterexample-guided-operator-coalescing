# Changelog

## 0.2.0 — 2026-10-31

This research release publishes the reviewed continuation implementation, its retained numerical evidence and portable evidence checks. It establishes no practical compression or counterexample-selection win.

- Separate recovery objective from trainable-owner scope, with immutable finite raw-window plans, explicit repeated/raw/operator counters and complete safe-boundary restore.
- Add initialization, composition, shared calibration/quantization, offline bundle and confirmation-access implementation controls. Actual protected evaluation remains unopened.
- Publish the checked one-pair/seed17 1,024-update comparison and twelve matched native points from the earlier 256-update model. Preserve the original local accounting failure and every historical receipt.
- Implement the fixed six-recipe dense baseline campaign, exact affine DWQ trainability, source/data/profile restore gates, ancestor cost accounting and complete resource-failure reports. Its seventeen native controls and six new measurements remain future work.
- Add a standard-library verifier for all42checkpoint files, raw reductions and scope assertions, with optional independent NumPy bootstrap replay and explicit rejection controls.
- Shorten the README, refresh software citation/version metadata and document the MIT terms on retained MLX-LM source archives.

Model weights, corpus/token files and optimizer states are not release assets. Numeric verification does not rerun training or inference. A smaller stored artifact, teacher-distribution fidelity, capability preservation and production performance remain separate claims.
